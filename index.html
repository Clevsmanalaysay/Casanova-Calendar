How to Put Live for Resort Team

Bookings now sync live through a shared cloud database (Firebase), so every visitor to the link sees the same calendar. Do Step 1 once, then host the file with Step 2 or 3.

1. One-Time: Connect the Shared Database (Firebase)

  1. Go to console.firebase.google.com and create a free project.
  2. In the project, open Build → Firestore Database → Create database, start in test mode, pick a region.
  3. Open Project Settings (gear icon) → General, scroll to "Your apps", click the Web </> icon, and register an app.
  4. Copy the firebaseConfig object it shows you, and paste it into this file's index.html near the top of the last <script type="module"> block, replacing the YOUR_... placeholders.
  5. In Firestore Database → Rules, paste: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
    then click Publish.

These rules make bookings readable and writable by anyone who has the link (no login) — that's what makes it "viewable by everyone," but it also means anyone with the link can edit or delete entries. Good for an internal team link; tighten the rules later if you need staff logins.

2. Netlify Drop (Fastest)

  1. Visit app.netlify.com/drop
  2. Drag and drop the folder containing this index.html file.
  3. You will instantly get a custom live web link to share with your staff!

3. GitHub Pages (Free Forever)

  1. Create a free account on GitHub.com.
  2. Create a new repository (e.g. casanova-calendar).
  3. Upload this file as index.html.
  4. Go to Settings → Pages, select main branch, and click Save.
